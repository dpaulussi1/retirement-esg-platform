# Retirement ESG Platform

A new Python project scaffold for the retirement ESG platform.

## Project structure

- `data/` - raw and processed data files
- `database/` - database schemas, migrations, or persistence files
- `docs/` - documentation and design notes
- `notebooks/` - exploratory Jupyter notebooks
- `reports/` - generated reports and visual outputs
- `src/` - application source code
- `tests/` - automated tests

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
```

## Notes

- Use `python3` to run scripts in this environment.
- Add dependencies to `requirements.txt` or a project config file as needed.
